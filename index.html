03

ONE-TIME SETUP · TELEGRAM

Create your subject’s bot.

BotFather is Telegram’s own bot-creation assistant. You chat with it inside Telegram to create your subject’s quiz bot. It is not a person you need to contact, and it is not your quiz bot.

Open the official BotFather ↗

Find BotFather in the Telegram app

  1. Open the Telegram app on your phone and go to Chats.
  2. Tap the Search bar or magnifying-glass icon. Type BotFather.
  3. Select the account with the exact username @BotFather and a verification tick beside its name. Ignore similarly named accounts. The button above is a shortcut to this same account.
  4. Tap Start at the bottom of the conversation. If you already see a message box, continue to the next step.

Create your own quiz bot

  1. In BotFather’s message box, type /newbot, including the slash, then tap the Send arrow.
  2. When it asks for a name, type a display name students should see, such as Geography Practice, and send it. Spaces are allowed in the display name.
  3. When it asks for a username, send a unique username ending in bot, such as ExampleGeographyPractice_bot. Use letters, numbers and underscores only—no spaces. This is an example; choose your own available username. If BotFather says it is taken, send another.
  4. Look for the confirmation containing “Use this token to access the HTTP API”. Copy the entire token beneath it, including the leading numbers and the colon. Do not copy the bot’s name, username, t.me link or surrounding message text.
  5. Return to your copied Google Sheet, open Dashboard, select cell E1, paste the token, then press Enter. Leave E2 and E3 blank for now.
The leading numbers ARE part of the token.

A token has three joined parts: numbers + colon (:) + secret text. For example, 123456789:EXAMPLE_ONLY illustrates the structure; it is not a usable token. Copy your real token in full as one continuous string, without spaces, quotation marks or a line break. The numbers identify the bot, but must not be removed from the token pasted into E1.

Ready for Step 04?

You now have your own workbook and a bot token in Dashboard E1. Leave your questions unchanged until the first test.

Treat the token like a password.

Do not post it in a class group, paste it into this guide, or share it with students. If it is exposed, regenerate it through BotFather and update E1.

Use one bot for this workbook. Reusing its token in another independently deployed workbook can redirect incoming answers to that other deployment.

Official reference: Telegram’s BotFather instructions.

04

ONE-TIME SETUP · GOOGLE SHEETS

Connect the two services.

Complete A, then B, then C. You need your own workbook with the bot token already in Dashboard E1. A webhook lets Telegram send group-connection messages, answers and button taps to your script.

A. Authorise your copy

  1. In your copied workbook, choose Extensions → Apps Script. Keep the workbook open in its other tab.
  2. Select onboarding.gs in the Files list.
  3. In the function dropdown above the code, choose setupClassOnboarding, then click Run. You can do this before entering any classes.
  4. If an Authorization required box appears, click Review permissions. Select the Google account managing your copied workbook.
  5. Read the requested permissions, then use Google’s Allow or Continue button if you trust your copy. The script needs access to the sheet, Drive images and external services including Telegram.
  6. Return to the Apps Script editor. If the first run did not continue after authorisation, select setupClassOnboarding and click Run again.
  7. Check the execution log for Execution completed. Return to the workbook: the bot’s username should appear in Class Registry!S2. Resolve any error before continuing to B.

WHY THIS STEP?

A · Give permission

Allow your copied script to use the Google services it needs and contact Telegram. This setup also identifies your bot and prepares the class registry.

Result: authorised copy + bot username in S2.
If your school blocks authorisation or external web apps

Ask your Google Workspace administrator to review the setup. Do not bypass a school restriction or use another account without approval.

B. Create the web-app address

  1. In the Apps Script editor, click the Deploy button at the top right, then choose New deployment.
  2. Choose Web app. If no type is selected, click the gear/type icon beside Select type, then select Web app. If Web app is already selected, leave it selected.
  3. Enter a description, such as Initial quiz bot setup.
  4. Set Execute as → Me (your managing Google account), and Who has access → Anyone. Telegram must reach the webhook without signing into Google. This also makes the template’s Send Poll page reachable by anyone who has the address; keep it within the coordinator team.
  5. Click the Deploy button inside the dialog. If Google requests authorisation again, review and complete it as in A. Wait for the successful deployment confirmation.
  6. Under Web app → URL, click its Copy button. Copy the full address ending in /exec—not the Deployment ID or Library URL, and not a /dev address.
  7. Switch to your workbook, open Dashboard, paste that address into E3, then press Enter. Close the deployment confirmation with Done if it is still open.
I closed the deployment confirmation before copying the URL

In Apps Script, choose Deploy → Manage deployments. Select your deployment under Active, then use Web app → URL → Copy. Paste the address into Dashboard E3 and press Enter. You do not need another new deployment.

After deployment, continue to C below. Deploying creates the address; it does not yet tell Telegram to use it. Automatic quiz delivery is configured separately in Step 10.

WHY THIS STEP?

B · Create a receiving address

Publish an address that Telegram can reach. It supports onboarding, identified answers and streak-button taps—not just streaks. It does not create a sending schedule.

Result: your /exec URL in E3.

C. Register the connection

  1. Return to onboarding.gs.
  2. Select setupTelegramWebhookForOnboarding in the function dropdown, then click Run.
  3. Wait for Execution completed. To check the connection, select webhook.gs → checkTelegramWebhook → Run. Its log should show your E3 address, no continuing errors, and normally no pending updates.

WHY THIS STEP?

C · Tell Telegram where to send

Register the address from B with your bot. Incoming group connections, identified poll answers and claim-button taps can then reach your copy.

Result: Telegram is connected to your URL.

Keep the /exec address within your coordinator team. This template also exposes a Send Poll page at that address; it is not a sign-in-protected administration portal. Run quizzes from your spreadsheet dashboard and do not distribute the deployment URL to students.

You do not redeploy after changing questions, classes, image files or weekdays. Redeployment is needed if you later change script code. Use Deploy → Manage deployments → Edit → New version → Deploy to keep the same URL.

Official reference: Google’s web-app deployment guide.

ONCE FOR EACH CLASS

One class. One link.

Teachers create their groups. The class-specific link adds the bot and records the Chat ID automatically. No teacher needs to find or send you a Chat ID.

First-time setup: connect only a test group now.

Use one row with Class Code TEST-CLASS and a temporary group that you control. Keep other classes inactive. After Step 06 succeeds and your own content is ready, repeat these steps for the real classes.

The coordinator’s part

  1. Open Class Registry. Use one row per class.
  2. Fill B: Class Code, for example 27GEO-A. Add the year, class name and teacher name in A, C and D if helpful.
  3. Tick F: Active. In E, leave Anonymous Poll unticked if you want individual response logging and streaks.
  4. Open Extensions → Apps Script → onboarding.gs.
  5. Select setupClassOnboarding from the function dropdown and click Run.
  6. Return to the registry. A unique link appears in H: Onboarding Link for each row with a class code in B. Give each teacher only their class’s link.

You may rerun setup after adding classes. Existing tokens and links are preserved. The shortcut Quiz Bot → Set up / refresh onboarding runs the same function; reload the spreadsheet if the menu is missing.

07

EVERYDAY USE

Build your question bank.

Use one row per question in Questions. Replace or clear the four sample rows before launch. You can paste from another spreadsheet, but paste only into the input columns—not across the calculated columns.

Prepare the chapter names first: open Completed Chapters and enter your topics in column A. Then use exactly those names in Questions column J. Keep release dates blank while preparing content; Step 09 explains which chapters to enable before launch.

Column I is an unused hidden legacy column. Keep the existing layout; do not delete or move columns.

A reliable editing routine

  1. Fill A, B–E, J and N. Add F or H only if needed.
  2. Check that K contains a number from 0 to 3, L has a question ID, and M is blank.
  3. Make sure J matches the intended chapter title and the chapter is eligible.
  4. Test new content with a temporary group before a large rollout.

Feedback is trimmed to 200 characters by the app. If H is blank, students get a basic correct-answer explanation. Keep question text and options concise, especially when using images.

How do I add more rows?

The template’s formulas are filled through row 937. Type into the blank rows within that area. Beyond it, insert rows in the Questions tab and copy formulas from a neighbouring blank row in G, K and L into the new rows. Check that references adjust to each new row. Do not copy a used row’s “sent” value into M.

Can I change a question after it has been used?

For a substantial change, add a new question row rather than overwriting a used question. Keep used question IDs stable: do not sort, reorder or delete used rows once you have response history. The ID formulas depend on row position.

My question contains mathematical symbols

Plain text and Unicode symbols such as ×, ÷, ≤ and ≥ are easiest. For equations, diagrams or complex layouts, use a clear image. If Telegram reports “can’t parse entities”, literal < or & characters in the formatted question may need escaping; ask your coordinator for help or use equivalent words/symbols.

08

OPTIONAL

Add a diagram or photo.

Images stay in a Google Drive folder that the script’s owner can access. The bot uploads the image to Telegram; students do not need direct access to your Drive folder.

  1. Create a Drive folder for quiz images under the account managing the bot. Upload clear PNG or JPG images.
  2. Open that folder. In a URL such as drive.google.com/drive/folders/FOLDER_ID, copy only the part after /folders/, stopping before any ?.
  3. Paste this folder ID into Dashboard!E2. Do not paste the full folder URL.
  4. Click Update Images List on Dashboard. Alternatively, select Code.gs → getFileNamesAndIds → Run. Authorise Drive access if requested.
  5. Open File List. Check that each filename has a file ID.
  6. In Questions!F, enter the exact filename, including its extension—for example river-cross-section.png. Column G should fill automatically.
  7. Send a test question and confirm that the image is readable on a phone.
Refresh the list after adding or renaming files.

Use unique filenames. Avoid nested folders: the image-list function reads files directly inside the chosen folder.

If G stays blank, the image will not be attached. Check the spelling, extension, file location and refreshed File List. Keep the combined question and options short enough for an image caption; long captions can be rejected by Telegram. Use only images you are permitted to share.

09

CONTROL WHAT STUDENTS RECEIVE

Release the right content.

In Completed Chapters, enter each chapter/topic in column A. Match the same wording in Questions column J. The question-count column calculates how many questions belong to that chapter.

Release by checkbox

Leave the unlock date blank and tick Completed when the chapter is ready. With Release only completed chapters ticked on Dashboard, only those checked chapters are used.

Release by date

Enter a real date in column B. Scheduled fullCode runs update Completed before sending: today/past dates become checked and future dates become unchecked.

If a date is filled, it takes precedence the next time fullCode updates chapters. Leave B blank for a purely manual checkbox. Before using manual SEND with date-based chapters, run updateStatusBasedOnDate in Code.gs, or check the Completed boxes yourself.

Dashboard choices
SettingUntickedTicked
Release only completed chaptersAll named chapters in Completed Chapters are eligibleOnly chapters with Completed checked are eligible
Allow Repeat QuestionsOnly questions not marked “sent”Both sent and unsent questions are eligible

Each send selects randomly from the eligible pool. Questions are not sent in sheet order. If there are no eligible unsent questions, delivery stops with an error—add questions, release another chapter, or allow repeats.

What does “Clear Sent Questions” do?

It clears the “sent” markers in column M for the whole question bank. This makes those questions available again when repeats are off. It does not erase Poll Responses or User Streaks. Use it only when you intend to restart that delivery history.

10

SET IT ONCE, ADJUST WHEN NEEDED

Choose the days.
Then choose the time.

Two controls work together: Dashboard chooses which weekdays are allowed; an Apps Script time-driven trigger chooses when to run. Selecting weekdays alone does not create an automatic schedule.

A. Check your time zones

In Google Sheets, use File → Settings → Time zone. In Apps Script, open Project Settings → Time zone. Set both to Singapore / GMT+08:00 for this guide. This version checks weekdays and participation streaks using Singapore dates. Changing only a trigger’s time zone does not change that weekday logic; ask a maintainer to review the setup if your school needs another region’s calendar.

B. Select weekdays

In Dashboard, tick the desired days in B2:B8. For Monday, Wednesday and Friday delivery, tick those three days only. For a weekly Friday quiz, tick Friday only.

C. Create one daily trigger

  1. Open Extensions → Apps Script.
  2. Click the Triggers clock icon on the left, then Add Trigger.
  3. Choose function fullCode and deployment Head if that field is shown.
  4. Choose event source Time-driven, type Day timer, and your preferred hour window.
  5. Save and authorise if prompted. Check that one trigger is listed.
Choose fullCode, not sendPoll.

fullCode updates chapter release dates, checks today’s weekday, then sends one question. A scheduled sendPoll run bypasses the weekday check. You do not need a separate updateStatusBasedOnDate trigger.

Google’s time-driven delivery is approximate. A selected 8–9 am window does not promise 8:00 am. Your computer and spreadsheet do not need to remain open. Triggers run under the account that created them.

11

AFTER THE QUIZ

See how students are doing.

Students answer in Telegram. The quiz gives correctness feedback, and the explanation/lightbulb can show your feedback text. In identified polls, the bot also records answers and updates streaks.

Anonymous Poll in Class Registry column E
Unticked · identifiedTicked · anonymous
Student identity can be visible to group participantsVotes are anonymous
Individual answers logged in Poll ResponsesNo individual answer logging by this bot
Streaks updated; Claim streak button sentNo individual streak tracking or claim button

Three tabs, three purposes

  • Poll Map: technical record connecting a Telegram poll to its question and class group. Leave this for the bot.
  • Poll Responses: answer time, question ID, Telegram user details, selected option, correct/wrong result and streak values.
  • User Streaks: the latest consecutive-correct count and daily participation count for each Telegram user.

Correct-answer streak increases for a correct answer and resets on an incorrect one. Daily participation streak counts consecutive calendar days with an answer—not merely opening Telegram. It uses Singapore dates; days with no quiz can break that sequence. Streaks are per user across this bot, not separate for each class.

The sheet calls the participation field “daily_login_streak”. The Claim streak popup uses temporary cached results; vote first, wait a moment, then tap it. A much older claim can expire even when the answer remains in the workbook.

Keep student records within your approved teacher team.

Identified mode stores Telegram user IDs, available usernames, names and answers. Agree on the school’s preferred mode and explain it to teachers and students before launch.

12

KEEP IT MANAGEABLE

Pause, restart, or hand over.

For a new school year

  1. Untick Active for old classes. You may mark their Status as Archived.
  2. Add each new class on a new registry row with a new class code; tick Active when ready.
  3. Run setupClassOnboarding again and distribute the new links.
  4. Review chapters, weekday selections and existing triggers before restarting delivery.

Academic Year in column A is a label, not an automatic delivery filter. Any row meeting the delivery conditions can receive quizzes, including an old-year row that is still Active.

When a bot is removed from a group

The membership update should clear Bot Present and mark the row Needs attention. That group is excluded. Re-add the bot using the class link and confirm the row returns to Connected before expecting delivery.

When a new coordinator takes over

Review ownership/access to the workbook, bot and image folder. The new coordinator should authorise their account and review deployment ownership. Installable triggers run as their creator, so replace the outgoing coordinator’s schedule deliberately and avoid leaving two schedules active. Test the handover with one group.

What usually needs no code change

Questions, feedback, image files, chapter choices, weekdays, trigger times, class links and Active settings can all be managed through the sheet or the named setup functions. The Organic Adaptive Tester message remains disabled; re-enabling that optional feature is a separate coordinator/code-maintenance task.

13

WHEN SOMETHING DOESN’T LOOK RIGHT

Check the simplest thing first.

In Apps Script, Executions shows recent runs. Open a failed run and read its error. Do not share screenshots containing your token.

No onboarding link appeared in H

Confirm the class code is in B. Select onboarding.gs → setupClassOnboarding → Run—not onOpen. Check E1 contains your bot token and the run completed. Existing blank rows are intentionally skipped.

The link says the class is not active

Tick Active (F) for that row. Check its Status is not Archived. Open that class’s own link again.

It says the class link was already used

The link is connected to a different group. Do not use it for a second group or borrow another class’s link. Ask the coordinator to review the class’s existing connection.

The group connected, but no quiz arrived

Check Active, Connected, a populated Chat ID and Bot Present in Class Registry. Run previewClassDeliveryTargets. Then check eligible chapters, available questions and the send confirmation. If it is only automatic sending that fails, check a fullCode trigger exists and today’s weekday is ticked.

“No quiz recipients”

No registry row currently satisfies all delivery conditions. Do not manually invent a Chat ID. Finish onboarding at least one active class and verify the status and Bot Present fields.

“No chapters” or “No unsent questions”

Check chapter names in Questions J and Completed Chapters A. If completed-only mode is on, tick the relevant chapter. Add unused questions or enable Allow Repeat Questions deliberately. A bank exhausted with repeats off does not send.

Chat not found / forbidden / bot was kicked

Confirm the bot is still in the intended group and can post. Use the onboarding link to restore the connection where possible, then verify registry status. Read the exact failed-delivery message before resending.

The image is missing or the photo request fails

Check your folder ID in E2, ownership/access, a refreshed File List and an exact filename in F. G must contain an image ID. Shorten long captions and use a normal PNG/JPG image.

The answer index is #N/A or the wrong answer is marked correct

Copy the correct option text exactly from B–E into N. Check there are four distinct options and K is 0–3. Restore the K formula if it was overwritten; do not type the letter A/B/C/D into N unless the option text itself is that letter.

Votes arrive, but responses or streaks do not appear

Make sure Anonymous Poll is unticked. Check the webhook with webhook.gs → checkTelegramWebhook → Run. Its URL must match Dashboard E3 and the correct bot token. Vote in a new identified test poll, wait briefly, then check the logs.

“Vote first” after I already voted

Allow a short moment for Telegram’s answer update to reach the bot, then tap again. Check the webhook if the problem persists. Old claim results can expire from the temporary cache; the workbook is the longer-term record.

Too many questions / unexpected sending days

Inspect Triggers for duplicate or hourly timers. Use fullCode for scheduled sends; sendPoll bypasses weekday gating. Remember that manual SEND is immediate and independent of the schedule.

The menu, drawings or buttons are missing

Open the Google Sheet in a computer browser, reload it and wait for it to load. Use Dashboard → SEND for manual quizzes.

I made a copy, but setup or deployment is blocked

Make sure you are in your own Google Sheet copy, signed into its managing account. Review Google’s authorisation prompt. If Anyone access or required services are restricted by your school, ask the Workspace administrator to review them.
